## 2. Vercel
- vercel.com → Add New → Project → Repo "the-cleaner-bremen-mockup" importieren
- Framework Preset: **Other** · Build Command: leer · Output Directory: `.`
- Projektname **the-cleaner-bremen-mockup** → URL wird https://the-cleaner-bremen-mockup.vercel.app
- Seite ist per `noindex` (Meta, Header, robots.txt) für Suchmaschinen gesperrt.
